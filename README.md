# ShakespeareLLM
A custom fine-tuned Large Language Model (LLM) that converts ordinary email messages into the eloquent style of William Shakespeare. This custom LLM
runs locally (as opposed to via cloud compute), so make sure your GPU has at least 12 GB VRAM.

# Features
Input: Any modern-day email text<br/>
Output: A Shakespearean rendition, complete with “thee”s and “thou”s

# How to Run
Make sure you have the proper python libraries installed (via Anacoda or other vm), then run "python3 finaldemo.py"
